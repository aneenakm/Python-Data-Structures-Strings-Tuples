# Python Data Structures - Strings & Tuples 

## Overview

This repository contains my first Python assignment on fundamental data structures, completed using Jupyter Notebook. It covers string operations and tuple manipulation with practical code examples.

## Topics Covered

### 1. Strings

* String concatenation
* String indexing and slicing
* Reversing a string
* Extracting specific characters and words
* String methods: `upper()`, `lower()`, `capitalize()`, `count()`, and `replace()`

### 2. Tuples

* Creating tuples
* Concatenating two tuples
* Repeating tuple elements
* Accessing elements using indexing
* Extracting elements using slicing

## Technologies Used

* Python
* Jupyter Notebook

## How to Run

1. Clone or download this repository.
2. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
3. Run the cells sequentially to view the outputs.

## Learning Outcome

Practiced Python string manipulation, indexing, slicing, built-in string methods, and basic tuple operations.
